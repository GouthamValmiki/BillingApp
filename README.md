# 🌱 AgriBill

AgriBill is an iOS application built using SwiftUI that helps fertilizer and seed shop owners manage customers, generate invoices, track credit balances, record payments, and maintain billing history.

## ✨ Features

- 👤 Customer Management
- 🧾 Invoice Generation
- 💰 Credit & Payment Tracking
- 📊 Customer Summary Dashboard
- 📱 Modern SwiftUI Interface
- 💾 Local Data Storage

## 🛠 Tech Stack

- Swift
- SwiftUI (Beginner Level)
- MVC Architecture
- PDF Invoice Generation
- Git & GitHub
